| Field | Value |
|---|---|
| Name | Token created (funnel stage 2) |
| The promise it proves | UC-01: the developer gets the token the first run starts from |
| Definition and formula | Accounts of the cohort with an `entropy_token_created` at most 7 days after signup ÷ accounts of the cohort |
| Unit and aggregation window | A share of **accounts**; weekly signup cohort; read 7 days after the week ends |

| What decision changes when it moves | Low, or many tokens `issued_via = staff`: self-service tokens (DQ-04) go to the top of the backlog |
