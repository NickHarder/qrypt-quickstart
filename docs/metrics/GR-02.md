# GR-02: Agent median time to first key

Measured: not yet. The rounds run in Phase 8.

| Field | Value |
|---|---|
| Name | Agent median time to first key |
| The promise it proves | UC-03: the agent gets there in a developer's sitting, not in a long session |
| Definition and formula | The median of (end − start), in minutes, over runs of the round logged as success; start is the prompt, end the success line |
| Unit and aggregation window | **Minutes**, per round of 5, over successful runs only; read on the revised round |
| Data source, and where it is computed | `evidence/agent_runs.csv`, its start and end columns (Phase 8); counted into `AGENT_READINESS.md`, which a test keeps equal to the log. **It does not exist yet** |
| Target, and the reasoning | At most 10 minutes: **the brief's benchmark**.[^assessment] For a human, the 45-minute baseline is **the brief's assumption** and is not measured here |
| What gaming looks like, and the guardrail | A short time bought by counting only the easy runs: the median is over every successful run, and [DR-04](/metrics/DR-04.md) counts the failures |
| What decision changes when it moves | Over 10 minutes: the docs put the one working program higher and cut what the agent reads before it; the harness's 30-minute stop is never raised to make a run pass |

The overview of every metric is in [the key metrics](/KEY_METRICS.md).[^key-metrics]
