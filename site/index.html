Qrypt Quantum Entropy · Quickstart

An AES-256 key from quantum entropy

Target: your first key in under 10 minutes. One run uses 1 KiB of your entropy allotment.

Working through an AI coding agent? Give it llms.txt: the same quickstart as plain text, with the rules an agent must follow.

1. Get a token

Get an access token for the Entropy service from the Qrypt portal at portal.qrypt.com. If the portal does not let you sign up, ask your Qrypt contact for a token.

Put it in a file named .env in the folder you will run the quickstart from:

QRYPT_API_KEY=paste-your-token-here

Never commit .env: add it to .gitignore. Never paste the token into a screenshot, a recording or a chat with an AI agent.

2. Run the quickstart

Pick your language. Save the file next to your .env and run it there.

Python 3.10 or later, and two packages:

pip install cryptography python-dotenv

Then run:

python quickstart.py

Node.js 20.12 or later. Nothing to install: fetch and node:crypto are built in.

Then run:

3. What you should see

Success: an AES-256 key from Qrypt quantum entropy passed AES-GCM (key not shown).

Either script asks Qrypt for size=1. size counts KiB (1,024-byte blocks), not bytes: size=1 returns 1,024 bytes, and an AES-256 key needs 32 of them. It decodes the base64 block, takes bytes 0 to 31 as the key and bytes 32 to 43 as the AES-GCM nonce, encrypts and decrypts a sample, and prints the result. The key stays in memory: it is never printed, logged or saved.

Saw something else? Every message the quickstart can print is in Troubleshooting, with its cause and its fix.

The API is documented at docs.qrypt.com/eaas. This site sets no cookies and collects no data.
